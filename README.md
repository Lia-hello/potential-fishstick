# Changes in Popular Music Lyrics and Thematic Diversity Before and After 2023 Generative AI
Student Name: Xueqing Liao
This study examines whether the diversity of lyrical content and musical themes in popular music has changed noticeably before and after the widespread popularity of generative AI music tools around 2023.
This dataset contains popular music lyrics, release years and chord information. All data are collected from open public platforms including GitHub, Hugging Face and Kaggle Billboard datasets. I mainly used public API access to gather data legally and avoid potential music copyright issues.
To run the data collection Jupyter notebook, please install the required Python packages first: pandas, numpy, requests, matplotlib
A GitHub API token is required to access data through the GitHub API. Users must provide their own personal access token in the notebook to run the code properly. No other credentials are needed.
