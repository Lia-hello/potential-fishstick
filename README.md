# Changes in Popular Music Lyrics and Thematic Diversity Before and After 2023 Generative AI
Student Name: Xueqing Liao
This study examines whether the diversity of lyrical content in popular music has changed noticeably before and after the widespread popularity of generative AI music tools around 2023.
This dataset contains popular music lyrics, release years and chord information.
All data are collected from open public platforms using official APIs from GitHub and Hugging Face, combined with Billboard datasets from Kaggle. I legally gathered data through public API access to avoid potential music copyright issues.
To run the data collection Jupyter notebook, please install the required Python packages first: pandas, numpy, requests, matplotlib
A GitHub API token and proper authentication for the Hugging Face API are required to access data. Users must provide their own personal access tokens in the notebook to run the code properly. No other credentials are needed.
